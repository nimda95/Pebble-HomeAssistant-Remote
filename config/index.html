Reference

Pages

The config is a list of pages. Each page is its own remote with its own entity, watch buttons and style. Up and Down switch pages.

- name: TV                      # a TV or box: platform + entities
  platform: LG webOS
  media_player_id: media_player.tv
  ok: center                    # Select button (any key name)
  rows:                         # rows → columns → rows …
    - [power, home, back]
    - [[volume_up, volume_down], touchpad]

- name: AC                      # anything else: the page's entity
  entity_id: climate.living_room
  style: {theme: light, accent: '#0055ff'}
  rows:
    - [power, temperature]
  custom_actions:
    - name: power
      icon: mdi:power
      tap_action: {action: toggle}   # targets the page entity

entity_id is the page's main entity. Actions without a target use it (toggle, perform-action in its domain), and so do sliders and config.entity in templates. A remote. or media_player. entity also fills remote_id / media_player_id.

A page with platform (or a remote_id / media_player_id, defaulting to Android TV like the card) gets that platform's keys and apps. Other pages use only their custom_actions.

Watch buttons per page: ok:, up: and down: take an element name, none, or tap_action / hold_action / double_tap_action. Up and Down still switch pages on tap unless you set their tap_action. Add start: true to the page to open first; otherwise the watch reopens the last page used.

Share settings between pages with YAML anchors: - &tv {name: TV, platform: Roku, …}, then - {<<: *tv, name: Apps, rows: …}.

Style 
style:
  theme: dark          # or light
  accent: '#00aaff'    # pressed buttons, slider fill, page dot
  background: black    # page background
  button: '#555555'    # button background
  text: white          # icons and labels
  pad: '#005555'       # touchpad / circlepad background
  title: '#aaaaaa'     # page name and dots
  show_title: true
haptics: true          # also per page:
hold_time: 500         # ms
repeat_delay: 100
double_tap_window: 200

Colors are #rgb, #rrggbb, rgb() or names, mapped to the Pebble's 64 colors. A single element can set color and background.

Elements

button (default): tap, hold, double tap. hold_action: {action: repeat} repeats the tap while held.

touchpad: swipe for up/down/left/right, tap for center, swipe and hold to keep repeating. With drag_action it fires a step every few pixels you drag (dragpad).

circlepad: a round d-pad with five buttons. A drag_action turns the ring into a click wheel (template variable clockwise).

slider: range, step, vertical, entity_id, value_attribute, unit_of_measurement. It shows the entity's value (a percentage for a 0–1 range) and sends tap_action on release with {{ value }}.

Layout extras: width: 2 / height: 2 change an element's share of its row or column, and elements can be written inline in rows as a mapping.

Shortcuts: volume_buttons, navigation_buttons, dpad, numpad, dialpad, xpad, npad. An empty slot is null or ''.

Actions and templates

key, source, perform-action (or call-service), toggle, keyboard / textbox / search (dictate on the watch), repeat, none, and page (page: next | previous | 2 | Name). A list of actions runs in order.

Templates support {{ value }}, math, | float, | int, | round(n), | abs, a if cond else b, and Home Assistant state: states('sensor.x'), state_attr(config.entity, 'temperature'), is_state(…).

Not available on a watch: more-info, navigate, url, assist, fire-dom-event, eval, multi-finger and momentary actions.
